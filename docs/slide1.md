# Slide 1. Title

## 1. 슬라이드 역할

첫 번째 슬라이드는 발표의 표지 화면이다.
프로젝트의 제목, 팀명, 팀원 정보를 보여주고 발표의 전체 분위기를 설정한다.

이 슬라이드에서는 기술 설명을 하지 않는다.
대신 “AI 기반 에너지 관리”, “캠퍼스”, “참여형 절감 시스템”이라는 인상을 주는 것이 목표다.

## 4. HTML 영상 연출

배경은 어두운 네이비 또는 딥 블루 계열로 설정한다.
배경에는 캠퍼스 건물 실루엣과 전력 그래프 라인이 은은하게 움직이도록 한다.

화면에는 다음 순서로 텍스트가 등장한다.

1. 배경의 전력 그래프 라인이 먼저 천천히 나타난다.
2. `Competition-EMS` 제목이 중앙에 페이드인된다.
3. 부제 `참여형 경쟁 기반 에너지 관리 시스템`이 제목 아래 등장한다.
4. 한 줄 카피가 인용문처럼 등장한다.
5. 마지막으로 팀명과 팀원 정보가 하단에 등장한다.

---

## 5. 디자인 방향

### 전체 분위기

* 신뢰감 있는 AI 대시보드 느낌
* 공공문제 해결형 프로젝트 분위기
* 캠퍼스 에너지 관리 시스템 느낌
* 너무 게임처럼 보이지 않게 절제된 디자인

### 색상

* 배경: 딥 네이비 / 블루 그라데이션
* 메인 텍스트: 화이트
* 포인트 컬러: 청록 또는 그린
* 보조 텍스트: 연한 그레이

### 시각 요소

* 캠퍼스 건물 실루엣
* 전력 그래프 라인
* 데이터 네트워크 노드
* 에너지 아이콘
* 은은한 대시보드 카드 형태

---

## 6. 녹화 지시

* 영상 길이: 약 5초
* 화면 비율: 16:9
* 해상도: 1920x1080
* 시작 화면: 어두운 네이비 배경과 희미한 전력 라인만 보이게 한다.
* 1초: `Competition-EMS` 제목이 페이드인된다.
* 2초: `참여형 경쟁 기반 에너지 관리 시스템` 부제가 등장한다.
* 3초: 한 줄 카피가 등장한다.
* 4초: 팀명과 팀원 정보가 하단에 등장한다.
* 5초: 모든 텍스트가 보이는 상태로 유지한다.

PPT에 삽입할 영상이므로 텍스트는 크게 표시하고, 작은 글자는 사용하지 않는다.

## 7. 발표자 멘트

안녕하세요. 저희는 팀 Aice입니다.
저희가 제안하는 시스템은 Competition-EMS, 즉 참여형 경쟁 기반 에너지 관리 시스템입니다.

저희는 전력 절감이 단순히 예측 시스템을 잘 만드는 것만으로는 어렵다고 보았습니다.
전력 절감은 예측하는 사람이 아니라, 실제 전기를 쓰는 사람이 참여할 때 가능하기 때문입니다.

## 8. Antigravity 구현 지시

이 파일을 기준으로 첫 번째 발표 화면을 구현한다.

구현 조건은 다음과 같다.

1. 16:9 비율의 발표용 화면으로 제작한다.
2. 메인 제목 `Competition-EMS`를 화면 중앙에 가장 크게 배치한다.
3. 부제 `참여형 경쟁 기반 에너지 관리 시스템`을 제목 아래에 배치한다.
4. 한 줄 카피 `전력 절감은 예측하는 사람이 아니라, 전기를 쓰는 사람이 만든다.`를 강조한다.
5. 하단에는 `2026 HUSS AI 경진대회`, `Team Aice`, `전승환 · 문효은 · 이승은 · 조명원`, `영남대학교`를 배치한다.
6. 배경에는 캠퍼스 건물 실루엣, 전력 그래프 라인, 데이터 네트워크 느낌을 은은하게 넣는다.
7. 발표자 멘트는 화면에 넣지 않는다.
8. 최종 화면은 PPT에 영상으로 삽입할 예정이므로, 텍스트가 녹화 후에도 잘 보이도록 크게 구성한다.
